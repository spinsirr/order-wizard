# Project agent instructions

The `/ship` skill is disabled for this repository. Do not invoke it, including
for requests to commit, open a PR, or prepare a release. Follow the repository's
normal checks and PR workflow instead.

Do not automatically start an Ensemble reviewer or require an `ensemble-review`
check as part of opening a PR. Independent agent review requires an explicit
user request.

See [CLAUDE.md](CLAUDE.md) for development commands and code conventions.
